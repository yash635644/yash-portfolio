# yash-portfolio

Portfolio of **Yash Trivedi**, Jr. AI Automation & SEO Executive at Jenex Technovation, Ahmedabad. Covers technical SEO, AI-search optimization (AEO/GEO), AI automation and AI-powered app development.

Live: https://yash635644.github.io/yash-portfolio/

## Files

| File | Purpose |
|---|---|
| `index.html` | Single-page site with meta tags, Open Graph and JSON-LD (Person, ProfilePage, WebSite, FAQPage, projects ItemList) |
| `style.css` / `script.js` | Styles and interactions (neural-net canvas, reveal animations, counters, typing effect, Formspree contact form) |
| `llms.txt` | Plain-language profile summary for AI assistants / LLMs |
| `robots.txt` | Allows search engines and AI crawlers, links the sitemap |
| `sitemap.xml` | Sitemap for Google Search Console / Bing |
| `yash-trivedi.jpg`, `og-image.jpg` | Optimised profile photo and 1200×630 social share image |
| `yash_resume.pdf` | Latest resume |

Plain static site with no build step. Push to GitHub Pages and it's live.
